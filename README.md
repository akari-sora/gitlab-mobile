# GitLab Mobile

Mobile-first Flutter GitLab client for Android and iOS. This is an independent, unofficial client, not a WebView wrapper.

## Development status

The G0 R1 source is being imported from the September 19, 2026 source handoff. Private-project access, account isolation, and repository reading are the first vertical slice. OAuth, MR editing, Issues, and CI management inside the app remain planned work.

CI setup is in progress. A passing connectivity check is **not** an application test or release approval. Android/iOS device acceptance remains outstanding.

Flutter baseline: **3.47.2**.
